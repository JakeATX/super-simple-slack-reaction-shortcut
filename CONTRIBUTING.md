# Contributing

Please open an issue with your OS, Slack version, keyboard layout, and what happened. Do not include private messages, credentials, or screenshots containing personal information.

Keep the installer usable without a compiler or extra runtime, and keep the shortcut restricted to Slack. Run the platform build script and its self-tests before submitting changes; for input-handling changes, also test the picker in Slack, ordinary comma typing, modified comma shortcuts, a different app, key release, and pause/quit.
